Deployment Guide: Affinity Tax Services

Target Environment: Ubuntu 20.04 / 22.04 LTS Server

Method: Direct File Upload (No GitHub)

Date: February 3, 2026

About this Document: This guide provides step-by-step instructions to deploy the ATS application by uploading files directly to your Ubuntu server.

1. System Requirements

  • OS: Ubuntu 20.04 LTS or 22.04 LTS
  • CPU: 1 vCPU minimum (2 recommended)
  • RAM: 2GB minimum (4GB recommended)
  • Storage: 10GB free space
  • Network: Static Public IP, Valid Domain Name

2. Initial Server Setup & Security

Step 2.1: Update System

Ensure your server has the latest security patches.

sudo apt update && sudo apt upgrade -y

Step 2.2: Configure Firewall (UFW)

Enable the firewall to block unauthorized access.

# Allow SSH (Port 22) - CRITICAL
sudo ufw allow ssh

# Allow Web Traffic
sudo ufw allow 80
sudo ufw allow 443

# Enable Firewall
sudo ufw enable

Step 2.3: Setup Swap Space

Recommended for servers with 2GB RAM or less to prevent build failures.

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

3. Environment Installation

Step 3.1: Install Node.js (v18)

curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs unzip

Step 3.2: Install MySQL Database

sudo apt install mysql-server -y
sudo mysql_secure_installation

Step 3.3: Install Nginx & PM2

sudo apt install nginx -y
sudo npm install -g pm2

4. Application Deployment (Direct Upload)

Step 4.1: Prepare Local Files

On your local computer:

  1. Remove node_modules folders to keep the zip file small.
  2. Zip the entire project folder into ats-app.zip.

Step 4.2: Upload Files to Server

Use SCP or FileZilla to upload the zip file to your server's /tmp/ directory.

scp ats-app.zip username@your_server_ip:/tmp/

Step 4.3: Extract Files on Server

On your server terminal:

# Create web directory
sudo mkdir -p /var/www/ats-app

# Unzip
sudo unzip /tmp/ats-app.zip -d /var/www/ats-app

# Set permissions
sudo chown -R $USER:www-data /var/www/ats-app
cd /var/www/ats-app

Step 4.4: Install Dependencies

# Frontend
npm install --legacy-peer-deps

# Backend
cd server
npm install
cd ..

Step 4.5: Configuration (.env)

Create your production environment file:

cp .env.example .env
nano .env

Ensure NODE_ENV=production and database credentials are correct.

Step 4.6: Database Setup

sudo mysql -u root -p

# In MySQL Shell:
CREATE DATABASE ats_db;
CREATE USER 'ats_user'@'localhost' IDENTIFIED BY 'StrongPassword';
GRANT ALL PRIVILEGES ON ats_db.* TO 'ats_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Run migrations:

npm run migrate

Step 4.7: Build Frontend

npm run build

5. Launch & Serve

Step 5.1: Start Backend (PM2)

pm2 start server/index.js --name "ats-backend"
pm2 startup
pm2 save

Step 5.2: Configure Nginx

Edit config file: sudo nano /etc/nginx/sites-available/ats-app

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        root /var/www/ats-app/build;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Step 5.3: Activate Site

sudo ln -s /etc/nginx/sites-available/ats-app /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

6. SSL Certificate (HTTPS)

sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
